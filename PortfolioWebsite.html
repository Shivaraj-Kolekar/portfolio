Development Progress

Click the image to zoom in.

Initial Design

I started by forking a portfolio template I found on GitHub. I liked the clear lines and block-based structure, but I wanted to make the website feel like my own. I used the template as a starting point and gradually changed the layout, typography and visual style to match my own design ideas. This allowed me to experiment with different structures while keeping a solid foundation.

Development

During development, I changed and reorganized a large part of the original code. I structured the project into clearer folders and rewrote the styling using Tailwind CSS. I learned Tailwind while working on the website, mainly by trying things out and applying what I learned directly to the project. This hands-on approach helped me become more comfortable with Tailwind while also improving my understanding of frontend development.

Results

Click the image to zoom in.

The final website is a personal portfolio with a clean, structured and block-based layout. Although it started from an existing GitHub template, I changed most of the design and code to make it fit my own style and needs.

Reflections

This project helped me improve both my frontend development and design skills. I learned how to work with Tailwind, organize a larger project and adapt existing code instead of always starting from scratch. Most importantly, it showed me how much I can learn by simply experimenting, building and figuring things out along the way.
